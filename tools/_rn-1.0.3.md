- **新增 Ctrl+J 聚焦侧栏搜索框**：侧栏文档搜索框新增内置快捷键 `Ctrl+J`，按下即聚焦搜索框并全选原有内容；若侧栏处于折叠状态会先自动展开，随后可直接输入关键词筛选文档，无需鼠标点击。该快捷键为内置固定绑定，不占用「设置 → 快捷键」中可自定义的快捷键表，同时移除了搜索框上冗余的「Ctrl J」提示气泡与对应样式。

- **全窗口预览时隐藏语言选择行**：全窗口预览以右侧编辑区容器为参照铺满，此前顶部的「语言选择」工具行仍占据一行高度；现改为全屏预览时自动隐藏该行，把纵向空间让给预览内容，切回「左右分栏」或关闭预览时自动恢复显示。

- **修复查找框按回车误把正文回车掉**：此前在「查找 / 替换」浮层的查找框中按 Enter，虽已阻止默认行为，但查找函数仍会同步把焦点抢回编辑器，导致同一次按键的后续事件投递到编辑器、在文档中插入换行；现改为当焦点仍停留在查找 / 替换输入框内时不抢焦点，Enter 只执行「查找下一个」，正文内容不受影响。
