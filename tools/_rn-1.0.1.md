- **修复富文本文档点击「保存」提示保存失败**：根因是「另存为」原生对话框的文件类型过滤器描述含品牌名「L.Note」中的点号，pywebview 的 `parse_file_type` 只接受 `[\w ]+ (*.ext)` 形式并会抛 `ValueError`，而该异常在平台 try 之外，直接导致整个保存流程失败；现前端过滤器描述改为「LNote 富文档 (*.json)」，Python 侧 `_ask_save_path` 对每条过滤器逐条校验、剔除非法项并在全部非法时回落到「所有文件 (*.*)」，双保险后保存恢复正常。

- **新建文档默认名称统一为「无标题 / 无标题 2 / 无标题 3 …」**：此前普通文档走「无标题」，而快捷键 `Ctrl+N` 及富文本 / 流程图 / 思维导图 / 笔记等入口走「未命名文档 N」，两套命名规则并存；现全部新建入口统一复用 `nextAutoTitle()`，按现有「无标题」文档数量追加序号，侧栏与标题框显示一致。

- **新建文档不再自动写入磁盘**：新建文档仅保存在本地存储，必须由用户显式点击「保存 / 另存为」才创建磁盘文件，此后编辑才会自动同步到磁盘；修复「新建的文档未经确认就落盘」的问题，未关联磁盘文件时状态栏显示「已保存」而非「已保存到磁盘」。

- **预览内容安全加固**：Markdown / HTML 预览挂载前新增「标签 + 属性」白名单净化（丢弃 `<script>` / `<iframe>` / `<object>` / 表单控件等，仅保留 `href` / `src` 等必要属性并校验 URL 协议，拦截 `javascript:` 等危险链接）；Mermaid 安全级别由 `loose` 收紧为 `strict`；`app.html` 新增 Content-Security-Policy，并把 HTML 预览 iframe 的 `sandbox` 收紧为仅 `allow-scripts`（去掉 `allow-same-origin`），杜绝预览内容逃逸。

- **高危原生 API 增加会话令牌校验**：Python 端对写盘、移动 / 删除文件、保存图片、执行更新安装包等高危方法要求首位参数携带本进程随机生成的令牌（`hmac.compare_digest` 恒定时间比对），令牌仅保存在前端模块作用域、页面内注入脚本无法读取，因而无法直接调用 `window.pywebview.api` 触发高危操作；前端所有高危调用统一改走 `callApi()` 自动前置令牌。

- **自动更新增加 SHA256 完整性校验**：下载完成后先进入「正在校验安装包完整性」状态，Python 端按 Gitee raw → GitHub raw → GitHub Pages 顺序拉取官方 `SHA256SUMS.txt`，与已下载临时文件的实际 SHA256 比对，一致才 `os.replace` 就位；校验和不匹配或无法获取官方值时删除临时文件并中止安装，防止下载被篡改或损坏。
