- **新增 AI 助手（自备密钥 BYOK）**：在「设置 → AI 助手」填入自己的 API Key（OpenAI 兼容接口，默认 DeepSeek）即可使用；密钥仅保存在本机配置文件，不写入任何文档、不上传第三方，界面只展示脱敏信息。

- **选中即用 AI 助手**：在正文中选中文本后，文本编辑器右键菜单 / 富文档浮动工具条会出现「AI 助手」，提供润色、续写、总结要点、扩写、纠错、生成大纲六种指令；结果在独立浮层流式输出，可随时停止，并支持「替换原文 / 插入到光标处 / 复制」。

- **AI 图表生成**：选中文本后可一键生成流程图 / 思维导图；AI 只产出结构与连线，节点坐标全部由本地布局器计算，确认后另建独立文档，不覆盖原文档。

- **未配置引导与边界保护**：未配置密钥时点击 AI 入口会引导前往设置；空选区、超长文本等场景给出明确提示；同一时刻只运行一个 AI 任务，切换文档或关闭面板会自动取消。

- **左侧文档列表支持左键拖动排序**：左键按住任意文档即可上下拖动调整顺序（4 px 阈值，不干扰单击打开文档与右键菜单），排序结果本地持久化。

- **自动更新竞态修复**：修复静默更新时安装器 `[Run]` 与守卫进程重复启动新版 exe 的问题（commit 90e0c01）。
