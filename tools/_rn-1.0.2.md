- **新增「预览显示方式」设置项**：设置 → 通用新增「预览显示方式」，可选「全窗口」与「左右分栏」，默认「全窗口」——打开预览时铺满右侧编辑区，阅读版面最大化，左栏文档列表与顶栏保持可见；选择「左右分栏」则回到原有的左右并排 + 可拖动分隔线布局。该设置随设置项持久化到本地，重启后保持。

- **修复预览区鼠标光标消失、文字无法选中**：根因是 `#preview-body` 无条件设置了抓手光标（`cursor: grab`）并禁用文本选择（`user-select: none`），本意只服务 Mermaid 图表的拖拽平移，却把 Markdown / HTML 预览的文字光标与选中复制能力一起禁掉了；现改为按预览类型区分——仅图表预览保留抓手光标与拖拽平移，Markdown / HTML 预览恢复正常文本光标，可正常选中复制文字。

- **修正全窗口预览的铺满范围**：上一版全窗口预览以整个软件窗口为参照定位，会把左侧文档列表栏一并盖住；现改为以「右侧编辑区容器」为参照铺满，预览只占满编辑区，左侧文档列表栏与顶栏始终可见，同时切换「全窗口 / 左右分栏」时不再残留上一次拖动留下的宽度。
