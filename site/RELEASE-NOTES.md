# L.Note v0.21.5 发布说明

> 本地 Notion 风文本编辑器：语法高亮 / Markdown 实时预览 / Mermaid 图表 / JSON·XML 格式化。
> 纯本地运行，数据保存在本地存储，无需联网、无账号。

## 下载

- 便携版（免安装，解压即用）：`L.Note-v0.21.5-win64.exe`
- 校验和：见 `SHA256SUMS.txt`（可用 `certutil -hashfile <文件> SHA256` 核对）

> 系统要求：Windows 10/11（需已安装 Edge WebView2 运行时，Win11 自带；Win10 一般已自动安装，缺失时首次启动会提示安装）。

## 使用说明

1. 双击 `L.Note-v0.21.5-win64.exe` 直接运行，无需安装。
2. 未签名程序首次运行可能出现 SmartScreen「未知发布者」提示：点击「更多信息」→「仍要运行」即可（详见下方「关于签名」）。
3. 数据保存在本机（浏览器 localStorage），换电脑/清理数据前请先用「导出」备份。
4. 想将图片 / `.md` / `.markdown` 文件双击直接用 L.Note 打开？可运行仓库内 `register-file-assoc.ps1`（仅写 HKCU，无需管理员权限）。

## 关于签名

当前发布包未做代码签名（无受信任 CA 证书），Windows SmartScreen 会提示「未知发布者」。这不影响功能与安全；如需消除提示，可购买 OV/EV 代码签名证书（约 ¥1000/年）后重新签名发布，后续版本可跟进。

## 更新日志（本版亮点）

**v0.21.5**

- **PDF 查看器**：文件树双击 /「打开方式」/ 导入菜单可直接打开 `.pdf`。基于 pdf.js 懒加载渲染（首次打开才加载，离线携带 cmaps 与标准字体，中文 CID 不乱码），支持翻页、缩放（Ctrl+滚轮/重置/适应宽度）、文本层选中复制、空白页检测告警；提供「提取为文本」与「复制内容」；PDF 以只读方式登记进侧栏，保存/导出/磁盘写回全链路拦截。
- **Word 文档查看与导入**：双击 `.doc/.docx` 打开模态查看器——`.docx` 经 mammoth 渲染为排版富文本并统计字数，旧版 `.doc` 由内置多格式解析引擎提取文本；支持一键「导入富文档」、「导入 Markdown」与「复制内容」；全程只读。
- **文档地图（小地图）**：编辑器右侧新增仿 VS Code 的 130px 代码小地图（Canvas 按行采样绘制全景缩略图），高亮视口框随滚动实时同步，点击 / 拖拽按比例跳转；顶栏开关状态持久化（仅文本文档显示）。
- **图片查看器升级为图片编辑器**：通过文件关联双击 /「打开方式」传入图片直接进入独立编辑窗口；支持旋转、水平/垂直翻转、裁剪框拖拽、尺寸调整（锁定宽高比 + 高质量重采样 + 锐化）、滤镜（亮度/对比度/饱和度 + 灰度/反色）；撤销/重置、覆盖保存、另存为。
- **文件关联注册脚本**：`register-file-assoc.ps1`（`.bat` 仅为包装）仅写 HKCU，将 `dist\L.Note.exe` 注册为常见图片格式与 `.md/.markdown` 的默认打开程序。
- **JSON 结构折叠**：新增 `json-brace` 折叠（跳过字符串/注释配对，单行紧凑 JSON 也可折叠）与 `json-auto` 全局兜底。
- **块编辑器图片增强**：图片块支持「更换图片」、插入即弹选择器、加载失败自动重试。
- **启动性能优化**：Mermaid（约 2.5MB）、PDF.js、mammoth 三个大库拆分为独立懒加载包，首次使用时才加载，启动时间大幅缩短。

**v0.21.4**

- 打开所在文件夹：文档菜单 / 顶栏菜单一键在系统文件管理器中定位文档（Windows 选中文件、macOS Finder 显示）
- 修复从 Excel/WPS 复制内容粘贴被误识别为图片的问题：粘贴改为文本优先，剪贴板携带文本时优先走文本粘贴，仅纯图片才按图片插入
- 新增选中文本右键菜单「翻译」功能：自动检测语言并中英互译，桌面版通过 worker 线程 + Python 桥接执行，界面不卡顿

**v0.20.44**

- 批量管理：批量删除完成后自动退出批量模式，关闭顶部批量工具栏
- 文档去重：按「完整路径 + 文件名」规范化判断（含正/反斜杠、大小写），重复导入同一文件不再产生重复条目，而是刷新并打开原文档
- 文档信息面板：新增「位置」项，显示文件所在目录（悬停可见完整路径）
- 磁盘文件保存：已有磁盘文件 Ctrl+S 直接覆盖保存；仅首次保存或无路径时才弹「另存为」，保存与另存为彻底分离
- 磁盘文件刷新：重新打开文档、窗口重新聚焦时自动读取磁盘最新内容（外部软件修改后同步）
- 启动优化：修复启动瞬间左侧闪现空白框
- JSON 工具：支持混合文本中仅序列化 JSON 片段（含半截 JSON），并在原文中高亮标记有问题的位置
- 查找/替换：修复弹窗偶发不显示、上一项/下一项导航失灵，弹窗可拖动，导航按钮重新设计
- 文档排序：排序功能增加开关，默认关闭（保持创建顺序稳定）
- 桌面版导入：改用原生文件选择器，导入文件自动关联磁盘路径
