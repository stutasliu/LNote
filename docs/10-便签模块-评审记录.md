## 1. 评审范围

对「便签模块」PRD（docs/09-便签模块-PRD.md）开展设计研发评审，覆盖标签系统、便利贴、便签集三个子模块的数据模型、交互边界、技术实现与回归风险。

## 2. 数据模型评审

### 2.1 文档字段扩展

| 字段 | 类型 | 说明 | 持久化位置 |
|---|---|---|---|
| `tags` | `string[]` | 文档标签数组 | 索引（随 persist 写入 `inkpad.docs.v1`） |
| `kind: 'sticky'` | 字符串 | 便利贴类型标记（普通文档无此字段） | 索引 |
| `color` | `string` | 便利贴颜色（hex） | 索引 |
| `pinned` | `boolean` | 复用现有置顶字段（便利贴同样使用） | 索引 |

结论：全部为**索引级新增字段**，不改正文存储通道（`inkpad.content.<id>`），对现有 `persist()` 的正文写逻辑零侵入。兼容旧数据：加载时 `tags` 缺失按 `[]` 处理。

### 2.2 便签集存储

| 字段 | 类型 | 说明 |
|---|---|---|
| `collections` | `Array<{id, name, docIds[]}>` | 集合数组，独立持久化到 `inkpad.collections.v1` |

结论：集合**持有文档引用**（docIds），文档不反向持有集合，避免两处维护不一致。删除文档（含彻底删除）时需同步从各集合 docIds 中移除。

### 2.3 便利贴复用文档体系

结论：便利贴作为 `kind='sticky'` 的文档记录，**复用** docs 数组、软删除回收站、批量管理、搜索过滤。差异点仅在渲染（卡片样式）与新建入口。减少新机制，降低回归面。

## 3. 技术方案评审

### 3.1 标签系统实现

| 模块 | 方案 |
|---|---|
| 状态 | `state.docFilter` 增加 `{mode:'tag', tag:'xxx'}` 形态（或扩展 `state.tagFilter`），渲染层复用现有 filter 逻辑 |
| 标签编辑浮层 | 新模态框 `tag-edit-modal`：输入框 + 已选标签胶囊 + 全部标签候选列表 |
| 标签区渲染 | `renderList` 之前渲染标签区（`els.tagList`），点击设置 `state.tagFilter` 后调用 `renderList()` |
| 搜索扩展 | `20-craft-init.js` 搜索过滤逻辑加入标签名匹配 |
| 持久化 | `05-store.js` persist 中序列化 `tags`，loadDocs 中兼容缺省 |

### 3.2 便利贴实现

| 模块 | 方案 |
|---|---|
| 数据 | 复用 docs 数组，`kind:'sticky'`；渲染时走独立 `renderStickyList()` |
| 新建 | FAB 菜单新增「新建便利贴」，`newDoc` 扩展 kind 参数 |
| 编辑 | 独立编辑浮层 `sticky-edit-modal`（标题 + 多行正文 + 色板 + 置顶） |
| 视图切换 | `state.docFilter` 增加 `'sticky'` 模式；导航区新增「便利贴」入口 |
| 删除 | 复用 `deleteDoc`（软删除）与回收站 |

### 3.3 便签集实现

| 模块 | 方案 |
|---|---|
| 存储 | 新模块 `state.collections`，独立 `inkpad.collections.v1` 键 |
| 视图 | 侧栏便签集区（集合卡片列表）；点击进入集合详情（`state.colFilter`） |
| 成员管理 | 文档三点菜单新增「加入便签集」弹窗；批量工具条新增「加入集合」 |
| 一致性 | 彻底删除文档时清理所有集合 docIds 引用 |

## 4. 交互评审

| 项 | 结论 |
|---|---|
| 标签入口 | 右键菜单 + 三点菜单 + 文档条目标签胶囊 三处，覆盖发现性 |
| 标签视图退出 | 点击标签再点（取消）或点击「最近」恢复默认视图 |
| 便利贴编辑 | 失焦自动保存 + Ctrl+S，与现有文档保存体验一致 |
| 便签集删除 | 二次确认弹窗，明确「仅删除分组，不删除文档」 |
| 批量加入集合 | 批量模式下选择文档后触发，复用现有批量工具条布局 |

## 5. 关键依赖

| 依赖 | 说明 |
|---|---|
| 现有 state/bus 架构 | 便签模块全部在 `state` 增加字段，沿用 `docs:changed` 事件驱动渲染 |
| persist/loadDocs | 扩展字段序列化；`inkpad.collections.v1` 新键 |
| 06-doc-list renderList | 扩展 filter 分支 + 标签区 + 便签集区渲染 |
| 16-doc-ops 新建 | FAB 新建流程扩展 kind 参数 |
| 批量工具条 | 新增「加入集合」按钮 |

## 6. 风险清单

| 风险 | 等级 | 影响 | 规避 |
|---|---|---|---|
| persist 字段扩展破坏旧数据 | 低 | 旧 localStorage 无 tags 字段 | loadDocs 兼容缺省，`tags || []` |
| 集合引用与文档删除不同步 | 中 | 集合内出现已删除文档 id | 删除文档（含批量/彻底删除）统一清理集合引用 |
| 便利贴复用文档体系导致视图串扰 | 中 | 标签/集合过滤误包含便利贴 | 各 filter 分支显式排除 `kind==='sticky'`（除便利贴视图与回收站） |
| 标签区过长 | 低 | 大量标签导致侧栏拥挤 | 标签区可折叠 + 按计数降序展示 |
| 回归风险 | 中 | 五视图、收藏、批量、查找替换 | 改后跑全量 E2E（47 用例）+ 手工回归 |
