# L.Note（Inkpad）功能列表

> 版本：v0.21.6　|　更新日期：2026-08-24　|　适用：Windows 桌面版（`dist/L.Note.exe`）

本文档完整列出 L.Note 的全部功能，按功能域分组，供产品、研发、测试与用户查阅。

---

## 1. 侧栏导航（飞书风格）

| 功能 | 说明 |
|---|---|
| 最近 | 显示全部未删除文档，按 置顶 > 今天 > 昨天 > 本周 > 更早 分组 |
| 我的空间 | 全量文档视图 |
| 知识库 | 仅显示 Markdown 与富文档类文档 |
| 收藏 | 仅显示已收藏文档（★ 标记） |
| 回收站 | 显示已软删除文档，支持恢复 / 彻底删除 |
| 便利贴 | 独立于文档的轻量便签（卡片式），支持颜色 / 置顶 / 定时提醒 / 到期时间 / 删除进回收站 |
| 搜索框 | 实时过滤当前视图文档（标题/标签/集合名匹配，Ctrl+J 聚焦） |
| 工作区按钮 | 显示版本信息提示 |
| 侧栏折叠 | 顶部汉堡按钮动态切换收起/展开（≡▶/≡◀） |

## 1.0 定时能力（v0.21.1，便签模块）

| 功能 | 说明 |
|---|---|
| 便利贴定时提醒 | 单次 / 每天 / 每周（勾选星期）/ 每月（指定日期）+ 时分；到点应用内弹提醒弹窗 |
| 提醒防重复 | 同一提醒同一分钟只弹一次；配置随文档索引持久化 |
| 便利贴到期时间 | 可设/可清到期时间；卡片展示 已到期（红）/ 即将到期（黄）/ 到期时间 |
| 标签过期时间 | 标签右键设置 N 天过期 / 清除；未过期显示 ⏳；到期自动解除文档关联并消失 |

## 1.1 标签区（便签模块）

| 功能 | 说明 |
|---|---|
| 标签区 | 侧栏折叠区域，展示全部标签（名称 + 文档计数），按计数降序 |
| 标签过滤 | 点击标签过滤文档列表，再点取消；文档条目标签胶囊可点击跳转 |
| 编辑标签 | 文档右键 / 三点菜单「编辑标签」：添加、移除、候选标签点击添加 |
| 标签约束 | 每文档 ≤ 20 个，单标签 ≤ 20 字，重名拒绝，随索引持久化 |
| 标签过期 | 标签右键「设置过期时间 / 清除过期时间」；未过期显示 ⏳；到期自动解除文档关联并消失 |

## 1.2 便签集区（便签模块）

| 功能 | 说明 |
|---|---|
| 便签集区 | 侧栏折叠区域，展示集合卡片（名称 + 文档数） |
| 新建集合 | 便签集区「＋」或弹窗内新建，名称 ≤ 20 字 |
| 加入集合 | 文档三点菜单「加入便签集」多选；批量模式下批量加入 |
| 集合过滤 | 点击集合卡片查看集合内文档；再点取消 |
| 集合管理 | 右键集合：重命名 / 删除（仅删分组，不删文档） |

## 2. 文档管理

### 2.1 新建（底部 FAB）

| 功能 | 说明 |
|---|---|
| 新建文档 | 创建普通文本文档（Markdown） |
| 新建富文档 | 创建思维笔记富文档（块编辑） |
| 新建流程图 | 创建 Mermaid 流程图文档 |
| 新建思维导图 | 创建 Mermaid 思维导图文档 |
| 新建思维笔记 | 创建 InkpadNote 富文档 |
| 新建便利贴 | 创建轻量便利贴（卡片式，四色可选） |
| 打开文件夹 | 通过原生对话框打开本地文件夹 |
| 导入文件 | 导入本地文件为文档 |

### 2.2 打开 / 编辑 / 保存

| 功能 | 说明 |
|---|---|
| 打开文档 | 点击列表项打开；行内操作含 创建副本/重命名/收藏/置顶/导出/删除 |
| 保存 | 自动保存到 localStorage（去抖）；Ctrl+S 手动保存 |
| 保存到磁盘 | 顶栏「保存」按钮，写入磁盘文件（pywebview） |
| 导出 | 导出为文件（下载 Blob） |
| 另存为 | 指定文件名另存 |
| 打开所在文件夹 | 在系统文件管理器中定位当前文档（文档菜单 / 顶栏菜单） |
| 删除 | 软删除 → 回收站（可恢复）；回收站内支持彻底删除 |

### 2.3 文档组织

| 功能 | 说明 |
|---|---|
| 收藏 / 取消收藏 | 三点菜单操作，收藏视图聚合 |
| 置顶 / 取消置顶 | 三点菜单操作，置顶分组优先展示 |
| 创建副本 | 一键复制文档 |
| 重命名 | 弹窗输入新名称（空名拒绝） |
| 批量管理 | 批量模式：全选 / 已选计数 / 批量导出 / 批量删除（软删除）/ 退出 |

### 2.4 磁盘文件查看（PDF / Word，v0.21.5）

| 功能 | 说明 |
|---|---|
| PDF 查看器 | 双击 /「打开方式」/ 导入打开 `.pdf`：pdf.js 懒加载渲染（离线携带 cmaps/标准字体，中文不乱码），翻页 / 缩放 / 文本层选中复制 / 空白页检测；「提取为文本」转 Markdown 新文档、「复制内容」复制全文；只读登记进侧栏 |
| Word 查看器 | 双击打开 `.doc/.docx`：docx 经 mammoth 排版渲染 + 字数统计，旧版 doc 由内置多格式解析引擎提取文本；一键「导入富文档 / 导入 Markdown / 复制内容」；只读保护 |
| 文件关联注册 | `register-file-assoc.ps1/.bat` 仅写 HKCU，将 L.Note 注册为常见图片格式与 `.md/.markdown` 默认打开程序；双击图片进图片编辑器、非图片文档由主窗口打开 |

## 3. 编辑器

| 功能 | 说明 |
|---|---|
| 语法高亮 | 12 种语言：Markdown / JSON / XML / HTML / JavaScript / Python / CSS / SQL / Shell / YAML / C·Java·C++ / Mermaid |
| 括号自动配对 | 输入左括号自动补右括号 |
| 自动补全 | 代码提示补全 |
| 代码折叠 | 按缩进/语法折叠；支持折叠级别 1~5、折叠全部、展开全部 |
| JSON 结构折叠 | JSON 按花括号/方括号折叠（自动跳过字符串与注释），单行紧凑 JSON 也可折叠，数组折叠显示元素数「⋯ N 项」 |
| 文档地图 | 右侧 130px 代码小地图（仿 VS Code minimap）：视口内区域渲染文档真实文字缩略（迷你字号字符，可辨识段落形状与内容密度），视口外保留行长度色块；高亮视口框实时同步，点击/拖拽按比例跳转；顶栏开关持久化，仅文本文档显示 |
| 多光标 | 按住 Ctrl 点击多处同时编辑 |
| 行号 | 点击行号选择整行 |
| 字体缩放 | Ctrl+滚轮缩放编辑器字体（持久化） |
| 撤销 / 重做 | 编辑历史撤销重做 |

## 4. 预览与渲染
