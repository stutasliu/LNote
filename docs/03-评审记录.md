# L.Note（Inkpad）设计与研发评审记录

> 阶段三：设计与研发评审　|　版本：v0.20.44　|　状态：评审闭环归档　|　更新日期：2026-08-12
> 本文档沉淀 v0.20.x 历次设计评审与研发评审的议题、结论、依赖与风险，供后续迭代复用。

---

## 1. 评审背景

v0.20.x 期间围绕 **界面体系、文档组织、查找替换交互、工程架构** 四条主线开展了多轮设计与研发评审。核心诉求：在保持"功能全"的前提下，把界面做得像飞书一样干净统一，把交互做到顺手可靠，把工程做到可维护可验证。

## 2. 设计评审议题与结论

### 2.1 议题 D-1：信息面板视觉割裂

**问题**：编辑器右侧「文档信息」区域由多张不同底色/边框/阴影的卡片堆叠，视觉层级混乱。
**评审结论**：
- 合并为单一白色卡片，内部以分段式分组呈现；
- 去除冗余边框与阴影，统一底色与字号层级；
- 快捷操作按钮统一为文字/图标按钮，避免层级冲突。

### 2.2 议题 D-2：侧栏飞书风格化

**问题**：侧栏样式与飞书风格存在 7 处偏差。
**评审结论**（已逐条修复）：
| 项 | 标准 | 实现 |
|---|---|---|
| 侧栏宽度 | 240px | ✅ |
| 图标体系 | 线性 SVG 图标 | ✅ |
| 品牌区高度 | 64px | ✅ |
| 菜单项高度 | 48px | ✅ |
| 导航项 | 最近/我的空间/知识库/收藏/回收站 | ✅ |
| 时间分组 | 今天/昨天/本周/更早 | ✅ |
| 底部按钮 | 实心主色（#3370FF） | ✅ |

### 2.3 议题 D-3：查找替换弹窗交互

**问题**：顶栏标签页切换冗余；上/下按钮过小；下拉历史与「更多」菜单定位偏移；批量替换窗口样式异常。
**评审结论**：
- 移除顶栏标签页，恢复 `≪ 查找 / ≪ 替换` 折叠切换；
- 上/下按钮独立样式（32×30px，▲/▼ 12px 图标，hover 浅蓝底 + 蓝框）；
- 历史下拉对齐输入框、「更多」菜单右对齐按钮；
- 输入不再自动查找，改为手动触发（Enter / 按钮），避免干扰输入；
- 弹窗支持拖拽移动并记忆位置（✕ 点击除外）。

### 2.4 议题 D-4：顶栏按钮去重

**问题**：顶栏出现重复的汉堡按钮。
**评审结论**：合并为单一动态切换按钮（≡▶/≡◀），侧栏收起时仍可见，保证可逆性。

## 3. 研发评审议题与结论

### 3.1 议题 R-1：单文件巨型 IIFE 无法维护

**问题**：`app.js` 5,676 行单文件，248 个函数共享闭包，无法自动化测试。
**评审结论**：拆分 `src-app/` 20 个真实 ES Modules，`tools/build-app.js` 构建期打包；构建产物行为逐字等价（E2E 验证）。

### 3.2 议题 R-2：vendor 库与 npm 依赖迁移

**问题**：35 个 `vendor/*.js` 全局 script 依赖，版本失控、file:// 兼容风险。
**评审结论**：迁移为 6 个 npm 依赖（CodeMirror/marked/mermaid/highlight.js/KaTeX/diff），esbuild 打包单文件 IIFE `vendor-bundle.js`，保留 file:// 兼容。

### 3.3 议题 R-3：共享可变状态

**问题**：14 个模块间共享可变变量，循环依赖下易错。
**评审结论**：收拢为集中式 `state` 对象 + `bus` 事件总线；ESM import 只读约束；顶层副作用收敛为 `initEvents()`/`initApp()`/`initCraftSidebar()` 显式装配。

### 3.4 议题 R-4：查找上一个/下一个失效与卡顿

**问题**：正向查找依赖单次 `cursor.findNext()`，多行模式存在 CodeMirror SearchCursor 疑似 bug；每次点击全量扫描导致卡顿。
**评审结论**：
- 正/反向查找统一改为**迭代全部匹配后取目标**（与反向对称），修复光标不动；
- 缓存查询词（`state.frLastQuery`），连续点击跳过重复扫描；
- 统计与高亮移入 `setTimeout` 异步执行，避免阻塞交互。

### 3.5 议题 R-5：软删除与回收站设计

**问题**：删除即销毁，误删不可恢复。
**评审结论**：
- 普通删除（单删/批量）改为**软删除**：标记 `deleted=true` + `deletedAt`，正文保留；
- 回收站视图提供恢复/彻底删除；彻底删除才清理正文存储；
- `persist()` 持久化 deleted 字段；启动时 activeId 不指向已删除文档。

### 3.6 议题 R-6：17-events.js 导出崩溃

**问题**：ESM 导出列表含未声明变量 `btnToggleSidebar`，SyntaxError 导致全部按钮无响应。
**评审结论**：移除该未声明导出；同类问题纳入 ESM 迁移回归用例（导出绑定与实际声明一致）。

## 5. 技术方案要点

```
构建链：src-app/*.js(ESM) → esbuild → js/app.js(IIFE)
       src-vendor/main.js → esbuild → js/vendor-bundle.js(IIFE)
       Vite 合并 CSS/字体 → dist-web/
       PyInstaller(Inkpad.spec) → dist/L.Note.exe
测试链：Vitest 单测(源码级纯函数提取) + CDP 驱动 headless Edge E2E
```

- **file:// 兼容**：产物保持传统 script + 相对路径，支持 pywebview 打包场景直载。
- **CSS 分层**：base（主题变量）/ layout（布局与侧栏）/ components（组件）/ inkpad-rich（富文档）。
- **存储拆分**：索引与正文分离存储，规避 localStorage 5MB 上限拖垮列表。

## 6. 风险清单与规避

| 风险 | 等级 | 影响 | 规避措施 |
|---|---|---|---|
| ESM 循环依赖（15 模块成环） | 中 | 依赖 esbuild 提升变量，理解成本高 | 保留但不扩张；`analyze-deps.js` 提供拆层方向 |
| vendor/ 冗余 CSS/字体 | 低 | 打包体积略大 | 无害；可后续清理 |
| 测试固定端口冲突 | 低 | 多实例并行时 8321/8322/8323 冲突 | 单实例运行；可参数化端口 |
| 查找全量扫描性能 | 中 | 长文档卡顿 | 查询词缓存 + 异步扫描 + 迭代定位 |
| localStorage 超限 | 中 | 大文档内容丢失风险 | 索引/正文分离；磁盘文件兜底 |
| PowerShell 执行策略 | 低 | 本机脚本运行受限 | 构建经 npm scripts / 打包脚本规避 |
