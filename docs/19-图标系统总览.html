一、体系概览

来源：js/icons.js、src-app/01-core.js、app.html、css/base.css　Data-backed

项目内共有四套彼此独立的图标集合，分别服务于正文写作、文稿类型、界面控件与插入面板；另有一批以字符或 CSS 生成字形形式存在的图形，以及应用图标资源。四套集合共用同一套绘制语言：24x24 网格、fill="none"、stroke="currentColor"、圆头圆角连接，因此都能随字号缩放、随父级文字颜色变化。

集合边界

VECTOR 与 UI 在用途上互不重叠：前者进入 Markdown 正文，带 role="img" 与 aria-label，线宽 2；后者只做界面控件，aria-hidden="true"，语义交给相邻文字，线宽 1.6。UI 刻意不并入 VECTOR 与 names，否则会污染插入面板的「矢量图标」分类。

文字图标与内联 SVG 并存的现状

VECTOR 的 49 枚中，app.html 内以 class="ink-icon" 出现的次数为 0；界面里的图标目前一律走 UI / DOC_ICONS 的内联 SVG。正文写作时仍需在 Markdown 中写 :icon-名称:，由 js/md.js 的 processIcons 替换为内联 SVG。

命名

命名统一用小写与连字符，形式为「限定词 + 对象」，例如 chevron-down、file-pdf、ai-outline、json-format。名称中不出现尺寸、颜色或状态数值，形状变体另立名称，例如 star 与 star-filled、link 与 link-off。当前在用的限定词前缀包括 ai-、json-、file-、list-、zoom-、chevron(s)-、arrow-、link-、star-。

同名与同形

VECTOR 与 UI 之间有 19 个同名键：minus（同形）；file（异形）、folder（异形）、image（异形）、star（异形）、link（异形）、search（异形）、warning（异形）、plus（异形）、download（异形）、edit（异形）、trash（异形）、globe（异形）、smile（异形）、book（异形）、target（异形）、hash（异形）、info（异形）、check（异形）。异形同名意味着同一语义在正文与界面里画法不同，阅读时属于两套语境，不会同时出现；如后续合并，需先确认正文侧的既有文档。

集合内部还有 4 组完全相同的条目：VECTOR.code = VECTOR.code2；UI.sparkles = UI.ai-polish、UI.edit = UI.ai-continue、UI.check = UI.ai-fix。这些是别名而非复用，同一个 SVG 定义了两遍；新增图标时应先查本页，避免继续复制。

另有 2 个 UI 键与 DOC_ICONS 完全同形：chart、sticky。同形是刻意保留的：DOC 集带类型色，UI 集只取轮廓。

三、尺寸与颜色令牌

来源：css/base.css L26-39 / L55-88、css/layout.css L51　Data-backed

尺寸

图标不设固定像素刻度，一律 width:1em;height:1em 并随父级字号缩放，基线偏移固定为 vertical-align:-0.15em，因此图标与相邻文字共用一行基线，正文基线字号为 15px。需要更大或更小的表现时，改父级字号而不是改图标。

文稿类型色

每类文稿挂一个 .ico-<类型> 类，类上只设 color，SVG 内 stroke="currentColor" 随之取色。深色模式下同一批变量整体提亮，色相不变。

五、DOC_ICONS · 文稿类型图标

来源：src-app/01-core.js L43-125（9 枚）　Data-backed

九枚类型图标各自保留一个独占轮廓特征，保证在 16px 下仍可区分：文档是竖版页面加右上折角与三行正文，富文档在页面里放实心内容块，Word 在页面里放 W 形折线，流程图是矩形接箭头接菱形，思维导图是根节点加扇形曲线分支加圆点，思维笔记是圆点列加等长横线，便利贴是右下卷角，PDF 是横版页面加折角加两行，图表是三根柱状。

十二、维护约定

新增图标先判断归属：进入正文的写进 VECTOR 并另起名称，只做界面控件的写进 UI，文稿类型写进 DOC_ICONS 并同时在 css/base.css 的 --ico-* 里补一对浅色与深色值。

文案与图形分离：UI 图标一律 aria-hidden，按钮的可读名称由 title 或相邻文字承担；VECTOR 图标进入正文，必须保留 aria-label。

不复制既有形状。新增前先在本页检索名称与形状，撞形时复用已有定义，需要不同语义时改画法而不是换名字。

本文档的清单与统计由定义文件与标记文件直接读出，覆盖 js/icons.js、src-app/01-core.js、css/base.css 与 app.html。上述文件改动后，本页的清单、频次与一致性结论需要同步复核。

本页为静态总览，清单、频次与一致性结论均读自当前源码；相关文件变动后需同步复核。
