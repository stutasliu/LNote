## 1 软件概述

### 1.1 软件简介

L.Note 本地笔记编辑软件（以下简称本软件）是一款运行于 Windows 平台的本地笔记与文本编辑软件，界面采用飞书（Feishu）/Notion 风格的侧栏布局。本软件无需注册账户、无需连接网络即可完成全部日常操作；用户创建与编辑的文档、便签及个人设置均保存在本机，软件不向任何服务器上传用户数据。

本软件面向个人知识记录与文本处理场景，主要适用于以下工作：以 Markdown 语法进行写作与排版；富文本笔记的记录与管理；流程图与思维导图的绘制；代码片段及结构化文本（如 JSON、XML）的编辑与转换；PDF、Word、图片等本地文件的查看与简单编辑。

本软件由著作权人小先生独立开发完成，登记版本号为 V1.0，对应内部开发与发布版本 v0.21.13；本说明书所述功能与界面均以该版本为准。

### 1.2 软件主要功能

### 1.3 软件构成说明

本软件以 Windows 桌面程序形态提供，分为安装版与便携版两种分发形式。安装版通过安装向导写入系统，提供桌面快捷方式并可注册文件关联；便携版为免安装的可执行文件，双击即可运行，便于随身携带使用。

从技术构成上看，本软件的主体为本地网页界面：界面使用 HTML、CSS 与 JavaScript 实现，由桌面外壳调用 Windows 自带网页内核承载运行，并借助系统原生能力完成文件读写、文件对话框、窗口管理等桌面功能。软件不依赖第三方在线服务，也不要求用户安装任何开发运行环境。本说明书面向软件使用者，说明各项功能的操作方法；不涉及面向开发者的二次开发接口说明。

## 2 运行环境

### 2.1 硬件环境

本软件对硬件要求较低，普通办公电脑即可流畅运行。建议的硬件配置如下表所示，其中标注“待确认”的项目以软件发布说明为准。

| 项目   | 最低要求                    | 建议配置              |
| ---- | ----------------------- | ----------------- |
| 处理器  | 支持 x86\_64 指令集的处理器（待确认） | 双核及以上处理器          |
| 内存   | 待确认                     | 4 GB 及以上          |
| 硬盘空间 | 安装后约占用待确认 MB            | 预留 500 MB 及以上可用空间 |

在分辨率较低的屏幕上，界面元素可能出现显示不全的情况，可将系统显示缩放比例调低，或改用分辨率更高的显示器。

| 项目    | 要求                                                                               |

### 2.3 网络要求

本软件为本地应用，文档编辑、图表绘制、文本转换等常规使用完全离线进行，不强制联网，也无须注册或登录账户。

仅以下两类操作需要联网：一是软件每次启动时自动检查一次是否存在新版本；二是用户点击“检查更新”或“立即更新”按钮，联网查询版本信息并下载新版安装包。检查更新仅传输版本号等必要信息，不传输用户文档数据，详见第 17 章。

## 3 软件的安装与卸载

### 3.1 安装前准备

安装前请确认计算机满足第 2 章所列运行环境要求，并准备好软件安装包。安装版安装包的文件名为 `L.Note-setup-v0.21.13.exe`，体积约 18 MB（以实际下载文件为准），可从软件发布页面获取。

由于软件安装包未进行商业签名，Windows 自带的 SmartScreen 筛选器可能在运行时弹出“Windows 已保护你的电脑”提示。该提示仅说明安装包尚未通过微软签名验证，不影响软件安全性。如出现该提示，请点击“更多信息”，再点击“仍要运行”，即可继续安装。

### 3.2 安装步骤

安装版通过安装向导完成安装，操作步骤如下：

1. 双击安装包，启动安装向导，显示欢迎页面。【截图：安装向导-欢迎页】
2. 阅读软件许可协议。如同意协议条款，勾选相应选项并点击“下一步”继续。【截图：安装向导-许可协议】
3. 选择安装目录。保持系统默认目录即可，如需安装到其他位置，可点击“浏览”指定目录，然后点击“下一步”。【截图：安装向导-选择目录】
4. 确认安装设置，点击“安装”，等待进度条走完。【截图：安装向导-安装进度】
5. 安装完成后，向导显示完成页面，点击“完成”退出向导。桌面将生成 L.Note 快捷方式。【截图：安装向导-完成页】

### 3.3 启动与首次运行

1. 双击桌面上的 L.Note 快捷方式，或从开始菜单的程序列表中选择 L.Note 启动软件。
2. 软件首次运行时自动创建一篇“欢迎使用 L.Note”示例文档，并打开主界面。此后每次启动均直接进入主界面，文档列表保留上次的全部内容。【截图：首次启动主界面】

### 3.4 便携版使用说明

便携版文件名为 `L.Note-v0.21.13-win64.exe`，免安装，将文件复制到任意位置后双击即可运行。

便携版的数据存放位置与安装版相同，均保存在本机；由于不写入系统安装目录，便携版适合存放在 U 盘等移动存储设备中随身携带使用。便携版首次运行同样可能触发 SmartScreen 提示，处理方法与第 3.1 节相同。如软件在运行中发生异常退出，重新双击即可再次启动，不影响已保存的数据。

### 3.5 软件卸载

如不再需要使用本软件，可按以下步骤卸载安装版：

1. 打开系统“设置”，进入“应用”→“已安装的应用”。
2. 在应用列表中找到 L.Note，点击条目右侧的菜单按钮，选择“卸载”并确认。【截图：系统卸载列表（可选）】
3. 等待系统完成卸载。卸载程序只移除软件自身文件与快捷方式，不影响用户通过软件导出保存到磁盘的文档文件；关于卸载时是否清除软件内部数据，以卸载程序的最终提示为准。

## 4 主界面与基础操作

### 4.1 主窗口布局

启动软件后进入主界面，窗口整体分为四个区域：左侧侧栏、顶部工具栏、中间内容区与底部状态栏。

侧栏承载文档导航功能，显示文档列表、标签与便签集等信息；顶栏提供文档操作、工具与功能入口；内容区用于文档的编辑与预览；状态栏显示当前文档的语言、字符数、光标位置、保存状态等信息。【截图：主界面整体，建议分区标注图】

### 4.2 侧栏导航与视图

侧栏顶部提供五个视图入口，用于按不同维度浏览文档：

1. 最近：显示全部未删除文档，按“置顶、今天、昨天、本周、更早”分组排列。
2. 我的空间：显示全部文档的全量列表。
3. 知识库：仅显示 Markdown 文档与富文本文档。
4. 收藏：仅显示已收藏（带星标）的文档。
5. 回收站：显示已删除的文档，可在此恢复或彻底删除，详见第 5.8 节。

点击侧栏顶部的汉堡按钮，可动态收起或展开侧栏，以便在文档编辑时获得更大的内容区空间。【截图：侧栏视图切换】

### 4.3 搜索与过滤

当文档数量较多时，可使用侧栏搜索框快速定位文档。按快捷键 Ctrl+J 可将光标直接聚焦到搜索框；在搜索框中输入文字后，当前视图下的文档列表即按标题、标签或便签集名称实时过滤，仅保留匹配的文档。

此外，点击侧栏中某个标签或便签集卡片，文档列表会过滤为仅显示带该标签或属于该便签集的文档；再次点击同一标签或卡片可取消过滤，恢复完整列表。标签与便签集的创建和管理方法见第 5.6 节。

### 4.4 顶栏与状态栏

顶栏集中提供各项工具入口，主要包括：文档信息面板（可折叠，内含 JSON 工具、XML 工具、转换工具、文件比较、编码设置等快捷入口）、富文档大纲开关、更多菜单、语言选择下拉框以及预览开关等。更多菜单聚合了编码转换、文本工具、导出、设置、关于等入口。

状态栏位于窗口底部，实时显示当前文档的语言类型、字符数、光标所在行列位置、保存状态、编辑状态与编码等信息，便于用户随时掌握文档处理情况。

## 5 文档管理

### 5.1 新建文档

点击窗口底部左侧的“＋”按钮，弹出新建菜单，可选择创建不同类型的文档或导入外部内容：

1. 新建文档：创建一篇普通文本文档，采用 Markdown 语法编辑。
2. 新建富文档：创建思维笔记富文档，采用块级方式编辑，操作方法见第 11 章。
3. 新建流程图：创建 Mermaid 流程图文档，操作方法见第 9 章。
4. 新建思维导图：创建 Mermaid 思维导图文档，操作方法见第 10 章。
5. 新建便利贴：创建一张轻量便利贴，操作方法见第 12 章。
6. 导入文件：通过文件对话框选择本地文件，导入为文档。
7. 打开文件夹：通过文件对话框选择本地文件夹，将文件夹加入当前视图便于浏览。【截图：新建菜单】

新创建的文档会立即出现在侧栏文档列表中，并自动命名为默认标题，可直接开始编辑。

### 5.2 打开与切换

在侧栏文档列表中点击任意文档条目，该文档即在内容区打开。软件同时支持多篇文档轮流编辑：点击列表中不同条目即可在文档之间来回切换，内容区始终显示当前选中文档，各文档的编辑状态互不影响。已删除并进入回收站的文档不在普通视图中显示，需切换到回收站视图操作，见第 5.8 节。

### 5.3 保存

本软件采用自动保存机制：编辑过程中，内容会在操作停顿后自动保存到本机（去抖自动保存），一般情况下无需手动操作，也不会因忘记保存而丢失内容。

如需立即将文档写入磁盘文件，可点击顶栏的“保存”按钮或按快捷键 Ctrl+S，保存成功后状态栏会显示相应的保存状态。需要注意，“保存”将当前文档内容写入其在磁盘上关联的文件；如果该文档从未与磁盘文件关联，则按“另存为”处理（见第 5.4 节）。

### 5.4 导出与另存为

当需要把文档内容带到软件外部使用，或以指定文件名保存时，可使用以下两个功能：

- 导出：点击顶栏“导出”，将当前文档内容导出为一个文件下载到本地。该方法不改变文档原有的存储位置，适合制作分享副本。

- 另存为：点击顶栏“另存为”，弹出文件对话框，指定文件名与保存位置后，将当前文档内容以新文件保存。【截图：导出/另存为入口】

### 5.5 收藏、置顶、重命名与创建副本

将鼠标悬停在侧栏的文档条目上，条目右侧会出现“⋯”（三点）菜单按钮，点击后可按需执行以下操作：

1. 收藏 / 取消收藏：收藏后文档带星标，并集中显示在“收藏”视图。
2. 置顶 / 取消置顶：置顶后文档进入“置顶”分组，在“最近”视图中优先展示。
3. 重命名：弹出输入框，输入新名称后确认即可；名称为空时软件会拒绝重命名。
4. 创建副本：在当前文档基础上生成一份内容相同的副本文档。【截图：文档三点菜单】

上述操作在文档条目上点击右键弹出的菜单中同样提供。

### 5.6 标签与便签集

标签与便签集用于对文档进行分类组织：

- 标签：在文档的“⋯”菜单或右键菜单中选择“编辑标签”，打开标签编辑浮层。可在浮层中输入新标签名添加标签，点击标签上的“×”移除标签，也可以点击浮层中的候选标签快速添加。每篇文档最多可添加 20 个标签，单个标签不超过 20 个字符，重复的标签名会被拒绝。添加后，文档条目下方显示“#标签”胶囊，侧栏标签区展示全部标签及其文档计数。【截图：标签编辑浮层】

- 便签集：侧栏便签集区域以卡片形式展示各集合。点击便签集区域右上角的“＋”可新建集合；右键点击集合卡片可重命名或删除集合。删除集合仅删除分组本身，不影响集合内文档。在文档的“⋯”菜单中选择“加入便签集”，可勾选一个或多个集合完成归组；批量模式下可一次将多篇文档加入集合。【截图：便签集区域】

点击侧栏中的标签或集合卡片，即可过滤出带该标签或属于该集合的文档；再次点击取消过滤。

### 5.7 批量管理

当需要同时对多篇文档执行相同操作时，可使用批量管理模式：

1. 点击文档列表右上角的“批量管理”按钮，进入批量模式，顶部出现蓝色批量工具条。
2. 勾选目标文档（在批量模式下点击条目即切换勾选状态，不再打开文档），或点击“全选”选择当前视图全部文档。
3. 工具条显示“已选 N 项”，可执行批量导出（逐个导出为文件）、批量加入便签集，或批量删除（软删除，文档进入回收站，可恢复）。
4. 操作完成后点击“退出”，退出批量模式。【截图：批量模式】

### 5.8 回收站

删除的文档会先进入回收站，可在一定时间内恢复：

1. 点击侧栏的“回收站”视图，查看所有已删除文档，每个条目显示删除时间。
2. 恢复：点击条目上的“恢复”按钮，文档回到删除前所在的视图。
3. 彻底删除：点击条目上的删除按钮并确认，将彻底删除该文档。彻底删除后文档记录与正文均被清除，无法恢复，请谨慎操作。【截图：回收站视图】

普通视图中的删除属于软删除，可恢复；回收站内的删除为彻底删除，不可恢复。

### 5.9 外部文件打开与文件关联

本软件支持直接打开本机上的常见文件，按文件类型进入对应的查看或编辑界面：

- PDF 与 Word 文件（.pdf、.doc、.docx）：双击文件图标，或在“打开方式”中选择 L.Note，或经导入方式打开后，以只读方式查看内容。PDF 支持翻页、缩放与文本复制，并可将内容提取为 Markdown 文档；Word 文档经解析后显示正文并可一键导入为富文档或 Markdown 文档，详见第 11 章相关说明。

- 图片文件（常见图片格式）：双击打开后进入独立的图片编辑窗口，可进行旋转、裁剪、滤镜等编辑操作，详见第 13 章。

- 文件关联注册：软件附带文件关联注册脚本，运行后可将常见图片格式及 .md、.markdown 文件的默认打开方式注册为 L.Note，此后双击相应文件即可直接用 L.Note 打开。脚本仅写入当前用户的注册表项，不涉及系统级修改。

- 单实例接力：当软件已在运行时，再次通过文件关联或“打开方式”传入文档，系统不会打开第二个主窗口，而是将文档交由已运行的实例在当前窗口打开，并自动还原窗口置前，避免重复启动多个程序实例。

## 6 文本编辑器操作

本章说明文本编辑器的编辑方式与辅助功能，包括语言切换与语法高亮、编辑辅助、文档地图，以及撤销重做与字体缩放等。

### 6.1 语言切换与语法高亮

编辑器支持按内容类型切换语法高亮语言，操作步骤如下：

1. 打开任意文本文档，编辑器默认按文档类型匹配语言并以相应语法着色显示。

2. 如需切换语言，点击顶栏的语言下拉框，在列表中选择目标语言，编辑器立即按所选语言重新高亮渲染。

3. 语言下拉框提供 12 种语言选项：Markdown / JSON / XML / HTML / JavaScript / Python / CSS / SQL / Shell / YAML / C·Java·C++ / Mermaid。其中“C·Java·C++”为 C、Java、C++ 三种语言的合并高亮模式，“Mermaid”语言用于编写 Mermaid 图表文本。

4. 语法高亮随语言自动生效：关键字、字符串、注释、数字等元素以不同颜色区分显示，便于阅读与排查内容。

【截图：语言下拉与高亮效果】

### 6.2 编辑辅助

编辑器提供多项编辑辅助功能，使用方法如下：

1. 括号自动配对：输入“(”“\[”“{”等左括号时，编辑器自动补全对应的右括号，光标置于括号内部，可直接继续输入。

2. 自动补全：输入过程中按需弹出代码提示列表，可继续键入以过滤候选，按 Enter 或 Tab 键接受提示。

3. 代码折叠：点击行号旁的折叠标记，可按缩进或语法折叠代码块；折叠支持级别 1\~5、折叠全部与展开全部。JSON 文档支持按花括号、方括号结构折叠，折叠时自动跳过字符串与注释；单行紧凑 JSON 也可折叠，折叠后以“⋯ N 项”显示数组元素数量。

4. 多光标编辑：按住 Ctrl 键并依次点击多个位置，可同时放置多个光标，此后的输入、删除等操作在所有光标处同步生效。

5. 行号选择：点击行号可选中所在整行，按住拖拽行号可连续选中多行。

6. 右键菜单：在编辑区内点击右键弹出上下文菜单，提供撤销/重做、剪切/复制/粘贴/全选/删除选区等命令，并可按分组调用文本处理相关功能，详见第 14 章。

### 6.3 文档地图

编辑器右侧提供“文档地图”代码小地图，用于浏览与定位长文档，使用方法如下：

1. 小地图按真实行距渲染全文缩略视图，以迷你字号显示字符，可辨识文档的段落形状与内容密度；内容超出面板高度时，地图内部可独立滚动。

2. 高亮视口框随编辑器滚动同步移动，并自动带动地图滚动条；拖动地图滚动条或在空白处滚动，可反向跳转编辑器位置，实现双向联动。

3. 在小地图上点击或拖拽，可按比例跳转到文档对应位置；小地图仅绘制当前可见切片，超大文档浏览依然清晰流畅。

4. 顶栏提供小地图开关按钮，可随时显示或隐藏，开关状态自动记忆；小地图仅对文本文档显示。

【截图：文档地图】

### 6.4 撤销重做与字体缩放

编辑器支持撤销重做与字体缩放，操作方法如下：

1. 撤销与重做：编辑过程中按 Ctrl+Z 撤销上一步操作，按 Ctrl+Y 重做，也可通过右键菜单执行相应命令。

2. 字体缩放：在编辑区按住 Ctrl 键并滚动鼠标滚轮，可放大或缩小编辑器字体；缩放结果自动记忆，下次打开仍保持该字号。

## 7 查找与替换

本软件在文本编辑器中提供查找与替换功能，便于在长文档中快速定位内容并批量修改。操作步骤如下：

1. 打开文本文档，按 Ctrl+F，或点击顶栏的查找按钮，打开查找/替换浮层。浮层可拖拽标题栏移动位置，位置会被记忆，再次打开时保持原位。

2. 在查找输入框中输入查找内容，按 Enter 键或点击查找按钮手动触发查找。查找为手动触发模式，输入过程中不会自动执行检索。

3. 触发查找后，正文中的全部匹配项以高亮显示，当前匹配项以醒目样式标识，并自动滚动到可见区域。

4. 点击浮层中的“▲ 上一个”或“▼ 下一个”按钮，可在各匹配项之间前后导航，编辑器光标同步移动到对应位置。

5. 如需替换内容，展开替换区域并输入替换文本：点击“替换”按钮仅替换当前匹配项；点击“批量替换”按钮，确认后一次性替换全部匹配项。

6. 勾选“正则”选项后，查找内容按正则表达式规则匹配，可支持更复杂的模式查找。

7. 查找与替换的历史记录自动保留，可点击下拉框复用；常用查找规则可收藏保存，便于后续快速调用。

## 8 Markdown 预览与图表渲染

### 8.1 实时预览

Markdown 文档支持编辑与渲染结果同步显示的实时预览功能，操作步骤如下：

1. 打开一篇 Markdown 文档，点击工具栏中的“预览”开关，或通过顶栏“更多”菜单中的“切换预览”命令，开启预览区。

2. 开启后，编辑区与预览区分栏并排显示；渲染结果随编辑内容实时刷新，修改正文、调整标题层级、插入代码块或图片后，预览区立即同步更新，无需手动操作。

3. 再次点击“预览”开关，即可关闭预览区，恢复纯编辑视图。

【截图：Markdown 实时预览】

### 8.2 数学公式与代码高亮

预览区支持两类增强渲染，无需额外配置：

- 数学公式：正文中的行内公式（以单个美元符号 $...$ 包裹）与块级公式（以两个美元符号 $$...$$ 包裹）自动按数学排版渲染，适用于书写数学记号与公式推导内容。

- 代码高亮：Markdown 代码块内的代码按对应语言语法高亮显示，便于阅读与核对。

编写公式或代码后，可切换到预览区核对渲染效果，必要时回到编辑区调整语法。

【截图：数学公式与代码高亮】

### 8.3 图表渲染与预览区交互

在 Markdown 文档中编写 Mermaid 语法代码块后，预览区会将其实时渲染为流程图、时序图或思维导图等图表；流程图与思维导图文档的编辑与样式设置详见第 9、10 章。

预览区图表支持以下交互操作：

1. 拖拽平移：按住鼠标左键拖拽图表空白区域，可平移视图。

2. 缩放：按住 Ctrl 键并滚动鼠标滚轮，可放大或缩小图表显示比例。

3. 双击复位：双击图表区域，视图恢复为初始位置与默认缩放比例。

## 9 流程图编辑

流程图文档提供可视化画布，可在画布上直接添加、调整节点与连线，并支持泳道、样式设置等编辑能力。

### 9.1 新建与画布操作

流程图文档的创建方法详见第 5 章，创建后进入流程图编辑界面，画布基本操作如下：

1. 添加节点：在画布空白处点击右键，通过右键菜单添加节点；使用左键按住节点拖动，可调整节点位置。

2. 画布平移：按住鼠标左键拖拽画布空白区域，可整体平移视图。

3. 画布缩放：按住 Ctrl 键并滚动鼠标滚轮，可放大或缩小画布显示比例；双击画布可将视图复位到默认位置与比例。

【截图：流程图画布】

### 9.2 节点与连线

节点之间通过连线表达流程关系，操作方法如下：

1. 拖拽连线：从节点边缘的连接点按住鼠标向外拖出连线，移动到目标节点后松手，连线自动吸附完成连接，拖动过程中实时预览连线路径。

2. 连线模式连接：切换至连线模式后，依次点击两个节点即可在其间建立连线。

3. 端点重连：选中一条连线后，拖动其端点可重新连接到其他节点。

4. 连线形状：选中连线后，通过工具栏一键切换直线、曲线、折线三种形状；折线支持正交绕障路径，可自动绕开其他节点与障碍物。

### 9.3 泳道

泳道用于按角色或阶段对流程进行分区，相关操作如下：

1. 插入泳道：通过工具栏插入水平泳道、纵向泳道、双泳道或分割线。

2. 调整泳道：拖拽泳道标题栏可移动泳道位置，双击标题栏可重命名，右键菜单可删除泳道。

3. 节点归位：节点随泳道移动自动归位，并自动规避重叠；旧文档默认按水平泳道渲染，保持兼容。

【截图：泳道效果】

### 9.4 框选、样式与撤销

流程图画布支持框选、样式设置与撤销操作，说明如下：

1. 框选操作：在画布空白处按住鼠标左键拖拽，可框选多个节点；框选后支持整组拖动、批量删除，并可在样式面板中对多选节点批量应用样式。

2. 样式设置：点击流程图右上角的“样式设置”按钮（仅流程图文档显示），打开样式面板，可分别设置以下三类样式：

   - 节点样式：填充、边框、文字颜色（23 色色板）、线宽、线型（实线/虚线/点线）、圆角、加粗、斜体、字号。

   - 连线样式：线条与文字颜色、线宽、线型、箭头开关、字号。

   - 泳道样式：底色、标题栏、边框、标题文字颜色。

   样式修改实时预览，并随文档一并保存；点击按钮可开合样式面板并高亮按钮，点击面板外部区域自动关闭。

3. 撤销操作：按 Ctrl+Z 可撤销上一步画布编辑操作（模型快照栈，上限 50 步），与上述框选、样式操作相互独立。

## 10 思维导图编辑

思维导图文档以根节点为中心、子节点逐级展开的方式组织思路，支持节点增删改、复制粘贴、样式主题与聚焦模式等操作。

### 10.1 节点操作与右键菜单

节点是思维导图的基本组成单元，操作方式如下：

1. 右键节点：在节点上点击右键弹出上下文菜单，可执行添加子节点、添加同级、编辑、删除、复制、剪切、粘贴、折叠展开等操作；点击菜单外部区域自动关闭菜单。

2. 右键空白处：在画布空白处点击右键，弹出简化菜单，可添加根子节点或粘贴节点。

3. 拖拽重排序：按住非根节点拖动，可将其重新排列到兄弟节点之间；拖动时显示半透明幽灵元素跟随鼠标，并以蓝色插入指示线标记目标位置，松手完成排序。

【截图：思维导图右键菜单】

### 10.2 复制与粘贴

思维导图支持跨文档复制粘贴节点子树：

1. 选中节点后，按 Ctrl+C 复制、Ctrl+X 剪切、Ctrl+V 粘贴。

2. 复制时剪贴板同时写入 JSON（保留完整结构）与纯文本（缩进层级 Markdown）两种格式，跨文档粘贴仍能保留原层级结构。

3. 支持在不同思维导图文档实例之间相互粘贴，粘贴后可在新位置继续编辑。

### 10.3 样式与主题

节点与页面样式均可通过样式面板设置：

- 节点样式：在“节点”页签中设置填充、边框、文字颜色（23 色色板）、形状（矩形/圆角/椭圆/菱形/六边形）、线宽、线型、圆角、文字对齐（左/中/右）以及加粗、斜体、下划线、删除线等效果，字号可通过滑杆调整。

- 连线样式：可设置当前节点到父节点连线的粗细、线型（实线/虚线/点线）与箭头开关。

- 页面主题：在“页面”页签中可调整布局密度（紧凑/适中/宽松）与编号样式（无/1.2.3/A.a.c/Ⅰ.Ⅱ/一.二.三），并提供 12 套预设主题风格：经典、商务、彩虹、深色、亮色、田园、海洋、日落、森林、水墨、樱花、糖果，主题以网格卡片预览，点击即可应用。

【截图：主题网格】

### 10.4 布局与聚焦模式

- 平移画布：按住中心主题（根节点）拖动，可整体平移画布。

- 聚焦模式：按 Ctrl+\` 切换聚焦模式，仅高亮显示从根节点到选中节点的路径及其后代节点，其余节点变暗，便于集中处理当前分支。

- 节点调整：按 Shift+Tab 可将选中节点提升为父节点的同级节点；按 Ctrl+Delete 或 Ctrl+Backspace 可一键删除选中节点的所有子孙节点。

## 11 富文档（思维笔记）

富文档（思维笔记）采用块级结构组织内容，文档由文字、标题、列表、代码、表格、图片、公式等各类块组合而成，适合排版要求较高的笔记场景。

### 11.1 创建与块结构

富文档的创建方法详见第 5 章，创建后进入块编辑界面。内容以“块”为单位进行编辑：每个块占据独立行，光标置于块首时显示行首操作区，可新增空块、删除当前块或将块向上、向下移动；点击块外空白区域或按回车可另起新块。删除后保留标题层级、列表结构等格式信息，重新排版便捷。

【截图：富文档块编辑】

### 11.2 插入块

将光标定位到目标位置后，通过工具栏的“插入”入口或行首操作区，可插入以下类型的块：

- 代码块：插入后可选择代码语言并获得语法高亮。

- 图片：插入图片块时直接弹出本地图片选择器，选中即插入；已插入的图片块可选中后点击“更换图片”重新选择。

- 表格：弹出窗口设置行数与列数（行数 1\~50、列数 1\~20），可选首行为表头。

- 流程图 / 思维导图：插入后可编辑 Mermaid 图表。

- 图标、数学公式、标注提示、任务列表、引用、自动目录、分割线、分栏（两列）等：按内容类型一键插入。

### 11.3 大纲

左侧大纲面板以飞书式目录（TOC）展示文档标题结构，便于在长文档中快速定位：

1. 点击顶栏“大纲”按钮展开大纲面板，面板按标题层级列出全部章节标题。

2. 点击标题可跳转到正文对应位置；面板提供搜索框过滤标题，“上一个/下一个”按钮在标题间跳转，刷新按钮重新同步标题结构，并支持展开与折叠层级。

【截图：大纲面板】

### 11.4 格式工具栏与选中工具条

富文档提供两套排版入口：

- 选中工具条：选中文本后，光标附近自动浮出工具条，可快速设置加粗、斜体、链接等格式，无需在顶栏与正文间来回切换。

- 顶部格式工具栏：打开富文本文档时，顶栏中部显示 B/I/U、删除线、行内代码、引用、列表、表格等格式按钮，直接点击即可对选区或当前段落应用格式。该工具栏仅在富文本文档打开时显示，其他文档类型（纯文本、流程图、思维导图）自动隐藏，不影响顶栏右侧功能按钮的位置。

## 12 便利贴与定时提醒

便利贴用于记录临时想法与待办事项，支持定时提醒、到期时间与标签过期等时间管理能力。

### 12.1 便利贴创建

创建与编辑便利贴的方法如下：

1. 点击底部“＋”按钮，选择“新建便利贴”，自动打开编辑浮层并切换到便利贴视图。

2. 填写标题与正文，选择卡片颜色（黄、蓝、绿、粉四色），可按需勾选“置顶显示”。

3. 点击“保存”后，便利贴以卡片形式展示在便利贴视图中（通过侧栏“便利贴”导航进入）。

4. 点击卡片可再次进入编辑；卡片右下角的删除按钮将便利贴移入回收站，可恢复。

5. 置顶的便利贴卡片带有图钉标记与蓝色描边，在列表中优先排列。

【截图：便利贴卡片】

### 12.2 定时提醒

便利贴支持到点弹窗提醒，设置方法如下：

1. 新建或打开一张便利贴，在编辑浮层中勾选“定时提醒”。

2. 选择提醒类型：单次（选择日期与时分）、每天（选择时分）、每周（勾选周一至周日并选择时分）、每月（指定日期并选择时分）。

3. 点击“保存”完成设置。应用运行期间，到达设定时间后自动弹出提醒弹窗，显示便利贴标题与内容。

4. 同一提醒在同一分钟内只弹一次，避免重复打扰；应用未运行时提醒不触发。

【截图：提醒设置与提醒弹窗】

### 12.3 到期时间与标签过期

- 便利贴到期时间：在编辑便利贴时设置或清除“到期时间”。设置后卡片以状态徽标提示：已到期显示红色徽标，即将到期（24 小时内）显示黄色徽标，未到期时显示到期时间（MM-DD HH:MM）。到期仅作视觉提示，便利贴仍可正常编辑与删除。

- 标签过期：右键侧栏中的标签项，选择“设置过期时间”，输入过期天数（1\~365 天）并确定。未过期的标签显示沙漏标记，可右键“清除过期时间”；到期后系统自动解除该标签与所有文档的关联，标签从标签区消失，无需手动处理。

## 13 图片查看与编辑

本软件内置图片编辑器，可对常见格式的本地图片进行查看与基础编辑。

### 13.1 打开图片

打开图片并进入图片编辑窗口的方式如下：

1. 文件关联双击：若已运行文件关联注册脚本，双击图片文件即可直接用 L.Note 打开，进入图片编辑窗口。

2. “打开方式”传入：在系统“打开方式”菜单中选择 L.Note，将图片交由本软件打开。

3. 导入方式：通过软件内的导入入口将本地图片作为图片文档打开。

打开后进入独立的图片编辑窗口，图片居中显示，可进行后续查看与编辑操作。

【截图：图片编辑窗口】

### 13.2 编辑操作

图片编辑窗口提供以下编辑功能：

- 旋转与翻转：将图片旋转 90°，或进行水平、垂直翻转。

- 裁剪：拖拽裁剪框（四角带手柄）调整裁剪范围，确认后按选区保留画面。

2. 另存为：指定新的文件名与位置保存，原文件保持不变。

3. 编辑过程中支持撤销与重置，可随时退回上一步操作或恢复初始画面；退出编辑窗口时若存在未保存的修改，软件会提示可放弃修改后退出。

## 14 文本工具

文本工具面向文本文档的批量处理场景，提供 JSON/XML 格式化、编码转换、文本整理与代码段插入等能力，可通过工具栏下拉菜单或编辑区右键菜单调用。操作前先选中要处理的文本（不选中则默认处理全文），执行后结果直接替换当前选区。

### 14.1 JSON 与 XML 工具

- JSON 格式化：将 JSON 内容按 2 空格缩进重新排版，便于阅读与核对结构。

- JSON 压缩：去除多余空白，将内容压缩为紧凑形式。

- 转义 / 去转义：转义引号与换行符，或将转义后的内容还原。

- 对象转 GET 参数：将 JSON 对象转换为 query 字符串（?key=value&...）。

- XML 格式化：自动格式化并校验当前 XML 内容，格式错误时给出提示。

【截图：JSON 工具面板】

### 14.2 编码与转换工具

- Unicode ↔ 中文：将 \uXXXX 形式的内容解码为中文，或将中文编码为 \uXXXX。

- Base64 编解码：以 UTF-8 安全方式对文本进行 Base64 编码与解码。

- URL 编解码：对文本进行 URL 编码与解码，实现往返转换。

- 时间戳转换：打开转换弹窗，在时间戳与北京时间之间互转。

- 编码转换：设置或转换文档的字符编码。

### 14.3 文本处理

- 删除行：删除空行、重复行、行头空白、行尾空白、整行，以及删除到行头或删除到行尾。

- 行操作：行排序、按长度排序、反转行序、合并行、重新缩进。

- 注释切换：在选区上添加或移除注释标记。

### 14.4 代码段与剪贴板历史

- 插入代码段：从代码段列表中选择常用代码段，插入到光标当前位置。

- 剪贴板历史：查看近期复制过的内容记录，选择其中任意一条粘贴到当前位置。

## 19 数据存储与隐私说明

本软件以本地使用为设计原则，用户数据默认保存在本机，不依赖账号与网络服务。现就数据的存储方式与联网行为说明如下。

### 19.1 数据存储位置

1. 文档正文、富文档、流程图、思维导图、设置项、标签、便签集、便利贴等数据均保存在本机，由软件在本机的浏览器存储空间内统一读写，不写入外部数据库，也不发送到任何远程位置。

2. 软件不设账户体系，无需注册或登录即可使用全部功能；正常使用过程中，用户文档内容不会被上传至任何服务器。

3. 数据仅在本机读写。只有当用户主动执行“导出”或“另存为”操作时，软件才会将文档内容写入用户指定的本地磁盘文件，具体方法详见第 5.4 节。关闭软件、重启计算机或断开网络均不影响已保存数据的完整性。

### 19.2 联网行为

1. 启动时自动检查：软件每次启动时静默查询一次最新版本号；若已是最新版本，不做任何提示，不影响启动速度与正常使用。

2. 手动检查更新：用户打开“更多 → 关于 L.Note”窗口并点击“检查更新”按钮时，软件联网查询最新版本，操作方法详见第 17.1 节。

3. 上述联网操作仅查询并比对版本号信息，不包含任何用户文档数据。当计算机处于断网状态时，软件的全部本地功能均可正常使用，仅更新检查会显示“无法连接更新服务器”的提示，不影响其他操作。

## 20 常见问题与处理

以下列举使用过程中的常见问题及其处理方法：

问 1：双击安装包没有反应，或出现 Windows 安全提示，如何处理？

答：安装包未进行商业签名，Windows 的 SmartScreen 筛选器可能弹出“Windows 已保护你的电脑”提示，该提示不代表安装包存在问题。点击“更多信息”，再点击“仍要运行”，即可继续安装，处理方法详见第 3.1 节。若双击后完全无反应，请确认安装包已完整下载、文件大小与发布页面一致，必要时重新下载后再试。

问 2：打开 PDF 时中文显示为乱码，是什么原因？

答：本软件以只读方式打开 PDF 文件，相关说明见第 5.9 节。显示效果取决于 PDF 文件自身包含的字体与编码信息，若 PDF 未内嵌所需中文字体，个别字符可能出现显示异常。此时可将 PDF 内容提取为 Markdown 文档后再查看或编辑；也可先用其他 PDF 阅读器打开同一文件，确认是否为文件本身的原因。

问 3：更新提示窗中点击了“稍后”，之后如何再次检查更新？

答：点击“稍后”仅关闭更新提示窗，软件不会在本次运行中再次提示。如需更新，可打开“更多 → 关于 L.Note”窗口并点击“检查更新”按钮手动查询；也可在下次启动软件时等待自动检查，若仍存在新版本会再次弹出提示。相关流程详见第 17.2 节。

问 4：便携版与安装版之间的数据是否互通？

答：两版软件的数据均保存在本机各自对应的存储位置，互不自动共享。若需在另一版本中使用同一批文档，请先在来源版本中执行“导出”，将文档保存为本地磁盘文件（见第 5.4 节），再在目标版本中打开或导入。

问 5：误删了文档，如何恢复？

答：普通视图中的删除属于软删除，文档会先移入回收站。点击侧栏的“回收站”视图，找到目标文档后点击“恢复”按钮即可，文档将回到删除前所在的视图，详见第 5.8 节。

问 6：在回收站中彻底删除的文档能否找回？

答：不能。回收站中的删除为彻底删除，执行后文档记录与正文均被清除，无法恢复。为避免数据丢失，建议对重要文档定期使用“导出”功能备份到磁盘，详见第 5.4 节。
