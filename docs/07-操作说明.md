## 1. 快速开始

1. 双击运行 `dist/L.Note.exe`，首次打开自动创建「欢迎使用 L.Note」文档。
2. 点击左下角 **＋** 按钮，选择要新建的文档类型。
3. 左侧文档列表即显示所有文档；点击任意文档即可打开编辑。
4. 内容**自动保存**到本地（无需手动保存）；按 `Ctrl+S` 可立即保存到磁盘。

## 2. 文档管理

### 2.1 新建文档

| 操作 | 步骤 |
|---|---|
| 新建普通文档 | 点击底部 **＋** →「新建文档」 |
| 新建流程图 | 点击底部 **＋** →「新建流程图」（Mermaid） |
| 新建思维导图 | 点击底部 **＋** →「新建思维导图」 |
| 新建富文档 | 点击底部 **＋** →「新建富文档 / 新建思维笔记」 |
| 导入本地文件 | 点击底部 **＋** →「导入文件」，选择本地文件 |
| 打开文件夹 | 点击底部 **＋** →「打开文件夹」 |

### 2.2 打开与切换

- 点击侧栏中的文档条目即可打开。
- 侧栏顶部可切换视图：**最近 / 我的空间 / 知识库 / 收藏 / 回收站**。
- 使用侧栏搜索框（`Ctrl+J`）可实时过滤当前视图下的文档。

### 2.3 收藏 / 置顶 / 重命名 / 副本 / 导出 / 删除

1. 将鼠标悬停在文档条目上，点击右侧 **⋯**（三点）按钮。
2. 选择操作：
   - **收藏 / 取消收藏**：文档出现在「收藏」视图，条目出现 ★ 标记。
   - **添加到置顶 / 取消置顶**：文档进入「置顶」分组，条目出现 📌 标记。
   - **重命名**：弹窗输入新名称（空名将被拒绝）。
   - **创建副本**：生成副本文档。
   - **导出**：下载为文件。
   - **删除**：弹窗确认后移入回收站。

### 2.4 回收站：恢复 / 彻底删除

1. 点击侧栏「回收站」。
2. 每条文档显示「删除于 时间」。
3. 点击 **恢复**：文档回到原视图。
4. 点击 **删除（红）**：**永久删除**，不可恢复（记录与正文均清除）。

> ⚠️ 普通删除 = 软删除（可恢复）；回收站内的「删除」= 彻底删除（不可恢复）。

### 2.5 保存到磁盘

- 顶栏右侧 **保存** 按钮：将当前文档写入关联的磁盘文件（状态栏显示「已保存到磁盘」）。
- 顶栏 **另存为**：指定文件名保存。
- 顶栏 **导出**：导出为文件下载。

## 3. 编辑操作

### 3.1 语言切换

顶栏语言下拉框选择语言：Markdown / JSON / XML / HTML / JavaScript / Python / CSS / SQL / Shell / YAML / C·Java·C++ / Mermaid。

### 3.2 常用编辑

| 操作 | 方式 |
|---|---|
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y`，或右键菜单 |
| 剪切 / 复制 / 粘贴 | `Ctrl+X` / `Ctrl+C` / `Ctrl+V`，或右键菜单 |
| 多光标 | 按住 `Ctrl` 点击多个位置 |
| 选择整行 | 点击行号 |
| 代码折叠 | 点击折叠标记，或 文本工具 → 折叠（级别 1~5 / 全部 / 展开全部） |
| 字体缩放 | `Ctrl+滚轮` |
| 删除选区 | 右键 → 删除选区 |

### 3.3 右键菜单（编辑器内）

在编辑区右键弹出菜单，按分组提供：撤销/重做、剪切/复制/粘贴/全选/删除选区、**JSON 工具**（格式化/压缩/转义/去转义/Unicode↔中文）、**行操作**（合并行/行排序/重新缩进）、大小写转换、注释切换、删除行（空行/重复行/行头行尾空白/整行）、折叠全部/展开全部。

## 4. 文本工具

工具栏上方提供三组下拉工具（也可通过顶栏「更多」菜单或右侧信息面板快捷入口进入）：

### 4.1 JSON 工具

1. 选中要处理的 JSON 文本（或全文）。
2. 点击 **JSON工具 ▾** → 选择：格式化 / 压缩 / 转义 / 去转义 / 复制。
3. 结果替换当前选区。

> 右键菜单同样提供 JSON 格式化 / 压缩 / 转义 / 去转义 / Unicode↔中文。

### 4.2 转换工具

点击 **转换工具 ▾**：

| 功能 | 说明 |
|---|---|
| Unicode → 中文 | 选中 `\u4f60\u597d` 类文本 → 解码为中文 |
| 中文 → Unicode | 选中中文 → 编码为 `\uXXXX` |
| 转 GET 参数 | JSON 对象转 `?key=value&...` |
| Base64 编码 / 解码 | UTF-8 安全编码还原 |
| URL 编码 / 解码 | 文本 URL 编码往返 |
| 时间戳转换… | 打开弹窗，时间戳 ↔ 北京时间互转 |

### 4.3 文本工具

点击 **文本工具 ▾**，按子菜单选择：
- **大小写**：转大写 / 转小写 / 单词首字母大写 / 反转大小写
- **全半角**：全角↔半角
- **删除行**：空行 / 重复行 / 行头空白 / 行尾空白 / 整行 / 到行头 / 到行尾
- **行操作**：行排序 / 按长度排序 / 反转行序 / 合并行 / 重新缩进
- **折叠**：折叠级别 1~5 / 全部 / 展开全部
- **插入代码段…** / **剪贴板历史…**

### 4.4 XML 格式化

点击 **XML 格式化**：自动格式化并校验当前 XML 内容。

## 5. 查找与替换

1. 按 `Ctrl+F`（或顶栏 🔍 按钮）打开查找/替换浮层。
2. 输入关键词后按 **Enter** 或点击按钮**手动触发**查找（不会边输入边查找）。
3. 全部匹配高亮；当前匹配以醒目样式标识并自动滚动到可见区域。
4. 点击 **▲ 上一个 / ▼ 下一个** 在匹配项间导航，光标同步移动。
5. 切换 **≪ 替换** 进行单个替换或**批量替换**（弹窗）。
6. 勾选 **正则** 可按正则匹配；查找/替换历史可下拉复用，常用规则可**收藏**。
7. 拖动浮层标题栏可移动弹窗，位置会被记忆；关闭后重新打开位置不变。

## 6. 预览与图表

### 6.1 Markdown 预览

1. 打开一篇 Markdown 文档。
2. 点击工具栏 **预览**（或顶栏「更多」→「切换预览」）开关预览区。
3. 预览自动渲染：代码块高亮、`$...$` 数学公式（KaTeX）、Mermaid 图表。

### 6.2 Mermaid 图表

1. 新建「流程图」或「思维导图」文档（或插入 Mermaid 块）。
2. 编辑 Mermaid 语法，预览区实时渲染。
3. 预览区交互：**拖拽平移**、**Ctrl+滚轮缩放**、**双击复位**。

## 7. 富文档与大纲

1. 新建富文档（思维笔记）。
2. 顶部 **大纲** 按钮（或文档内大纲面板）展开飞书式 TOC：
   - 点击标题跳转；**▲/▼** 上一个/下一个标题；**↻** 刷新；搜索框过滤。
3. 选中文本弹出工具条（bubble menu）快速排版。
4. **插入 ▾** 可插入块：代码块 / 图片 / 表格 / 流程图思维导图 / 图标 / 数学公式 / 标注提示 / 任务列表 / 引用 / 自动目录 / 分割线 / 分栏（两列）。
   - 插入表格时弹窗设置 行数（1~50）× 列数（1~20），可选首行为表头。

## 8. 文件比较

1. 点击 **比较**（工具栏或顶栏「更多」→「文件比较」）。
2. 独立窗口打开双栏 diff，可加载本地文件参与比较。
3. 行级差异以 diff 高亮显示。

## 9. 批量管理

1. 文档列表右上角点击 **批量管理** 按钮，进入批量模式（顶部出现蓝色工具条）。
2. 勾选文档（点击条目即切换勾选，不再打开文档）；可点 **全选**。
3. 工具条显示 **已选 N 项**。
4. **批量导出**：逐个导出为文件。
5. **批量删除（红）**：弹窗确认后软删除到回收站（可恢复）。
6. 点击 **退出** 退出批量模式。

## 10. 常见问题

| 问题 | 解决 |
|---|---|
| 删除的文档不见了 | 进入侧栏「回收站」点击「恢复」 |
| 收藏的文档在哪看 | 侧栏「收藏」视图 |
| 为什么输入查找词没反应 | 查找为手动触发，请按 Enter 或点击按钮 |
| 弹窗挡住了内容 | 拖动浮层标题栏移动到合适位置（位置会记忆） |
| 如何放大编辑字体 | `Ctrl+滚轮` |
| 文档很大保存失败 | 本地存储有上限；建议「另存为/导出」到磁盘文件 |
| 右键菜单不弹出 | 按 `Ctrl+.` 或 Menu 键 / `Shift+F10` 兜底触发 |
| 数据安全吗 | 所有数据保存在本机浏览器本地存储，无网络请求、无上传 |
