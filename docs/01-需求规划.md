# L.Note（Inkpad）需求规划文档

> 阶段一：需求规划　|　版本：v0.20.44　|　状态：需求池维护中　|　更新日期：2026-08-12

---

## 1. 产品概述

L.Note 是一款**本地运行、隐私优先的 Notion 风文本编辑器**。它把「代码编辑器 + Markdown 笔记 + 可视化图表 + 文本工具箱」融合在单一桌面应用中，数据全部保存在浏览器本地存储（localStorage），无需联网、无账户、无数据上传。

| 项 | 内容 |
|---|---|
| 产品形态 | Windows 桌面应用（pywebview + WebView2 内核） |
| 定位 | 开发者友好型本地笔记 / 文本处理工具 |
| 核心价值 | 一条数据链路，覆盖写代码、写笔记、画图、文本加工全场景 |
| 交付方式 | 单文件可执行程序 `L.Note.exe`（PyInstaller 打包） |

---

## 2. 目标用户

| 用户画像 | 特征 | 核心诉求 |
|---|---|---|
| 开发者 / 运维工程师 | 常处理 JSON、XML、日志、脚本、Markdown | 随手格式化、转义、对比、画图，不离开本地 |
| 技术笔记用户 | 用 Markdown 记录知识、做个人知识库 | 语法高亮 + 实时预览 + 大纲导航 + 知识库分组 |
| 隐私敏感用户 | 不接受内容上云、拒绝账号体系 | 纯本地存储，数据不出本机 |
| 高频文本处理者 | 面对批量文本清洗、编码转换、正则查找替换 | 开箱即用的文本工具箱 |

## 3. 用户痛点（当前版本已解决 / 正在解决）

| # | 痛点 | 现状（v0.20.44） |
|---|---|---|
| P1 | 本地编辑工具功能分散：格式化、转义、对比、画图要开多个工具 | ✅ 已内置 JSON/XML 工具、文本工具、文件对比、Mermaid、时间戳、编码转换 |
| P2 | 在线笔记依赖网络、数据隐私无保障 | ✅ 全量 localStorage，无网络请求、无账户 |
| P3 | 查找/替换在长文档中定位困难、交互不友好 | ✅ 仿 EverEdit 查找替换（正则、高亮、批量替换、收藏规则），多次 UI 打磨 |
| P4 | 文档一多就难以组织：无收藏、无置顶、无回收站 | ✅ 飞书风格侧栏 + 收藏/置顶/批量管理 + 软删除回收站 |
| P5 | 单文件巨型代码难以维护、无法自动化测试 | ✅ 真实 ESM 模块化（20 模块）+ Vitest/CDP 自动化测试（47 用例） |

## 4. 使用场景

1. **日常写笔记**：新建 Markdown 文档 → 实时预览 → 飞书式大纲跳转 → 收藏常用文档。
2. **接口调试**：粘贴 JSON → 一键格式化 / 压缩 / 转义 → 对象转 query 参数 → 文件对比。
3. **绘制图表**：新建「图表文档」，用 Mermaid 画流程图、时序图、思维导图，实时渲染缩放。
4. **日志分析**：文本工具做去重、大小写转换、全角半角、Unicode↔中文、Base64、时间戳转换。
5. **知识库沉淀**：将 Markdown 文档归入「知识库」分组，置顶重点文档，回收站兜底误删。

## 7. 竞品分析与差异化

| 竞品 | 形态 | 优势 | 与 L.Note 的差异 |
|---|---|---|---|
| Notion | 在线/多端 | 协作、数据库、生态丰富 | 需联网、有账号；L.Note 纯本地、无账号 |
| Obsidian | 本地 | 双链、插件生态 | 基于文件目录；L.Note 侧重代码/文本处理工具 |
| Typora | 本地 | 所见即所得写作体验 | L.Note 同时覆盖代码编辑 + 文本工具箱 |
| EverEdit / 记事本++ | 本地 | 文本处理、正则替换 | L.Note 提供 Notion 风 UI + Markdown 预览 + 图表 |
| VS Code | 本地 | 全功能 IDE、扩展 | 重量级；L.Note 轻量即开即用 |

**差异化定位**：Notion 的颜值 + 代码/文本工具箱的能力 + 纯本地的隐私承诺，面向"既要好看又要能干活"的个人用户。
