## 使用建议

1. **新增需求**：在 [01-需求规划.md](./01-需求规划.md) 需求池登记 → 更新 [02-PRD.md](./02-PRD.md) EARS 表述与验收标准。
2. **设计/研发变更**：在 [03-评审记录.md](./03-评审记录.md) 追加评审议题与结论。
3. **排期跟进**：在 [04-研发跟进.md](./04-研发跟进.md) 更新任务状态与风险。
4. **发版前**：在 [05-测试验收.md](./05-测试验收.md) 对照验收清单回归，确认无上线阻断项。
