## 5. 边界与异常场景

| 场景 | 预期行为 | 是否覆盖 |
|---|---|---|
| 回收站为空 | 显示「回收站为空」 | 手工 |
| 收藏/知识库为空 | 显示对应空态文案 | 手工 |
| 当前活动文档被删除 | 自动切换到未删除文档 | 代码路径 + 冒烟 |
| 批量删除含当前文档 | activeId 切换正确 | 手工 |
| 重命名空名 | 拒绝并提示 | 代码路径 |
| 文档正文超 localStorage 上限 | 列表不受影响，正文跳过 | 代码路径 |
| 查找无匹配 | 保留缓存避免重复扫描 | 代码路径 |

## 8. 上线风险清单

| 风险 | 影响 | 建议 |
|---|---|---|
| 数据为纯本地，无备份机制 | 卸载/清缓存将丢失文档 | 提供「导出全部」入口建议；文档说明提醒 |
| 大富文档超 localStorage 上限 | 正文仅存磁盘文件 | 已有磁盘兜底；提示用户关联磁盘文件 |
| 打包体积（vendor 冗余） | 分发文件略大 | P2 优化项，不影响功能 |
| E2E 依赖 CDP 环境 | 偶发不可用 | 重跑即可；不影响生产 |
