# L.Note v0.20.44 发布说明

> 本地 Notion 风文本编辑器：语法高亮 / Markdown 实时预览 / Mermaid 图表 / JSON·XML 格式化。
> 纯本地运行，数据保存在本地存储，无需联网、无账号。

## 下载

- 便携版（免安装，解压即用）：`L.Note-v0.20.44-win64.exe`
- 校验和：见 `SHA256SUMS.txt`（可用 `certutil -hashfile <文件> SHA256` 核对）

> 系统要求：Windows 10/11（需已安装 Edge WebView2 运行时，Win11 自带；Win10 一般已自动安装，缺失时首次启动会提示安装）。

## 使用说明

1. 双击 `L.Note-v0.20.44-win64.exe` 直接运行，无需安装。
2. 未签名程序首次运行可能出现 SmartScreen「未知发布者」提示：点击「更多信息」→「仍要运行」即可（详见下方「关于签名」）。
3. 数据保存在本机（浏览器 localStorage），换电脑/清理数据前请先用「导出」备份。

## 关于签名

当前发布包未做代码签名（无受信任 CA 证书），Windows SmartScreen 会提示「未知发布者」。这不影响功能与安全；如需消除提示，可购买 OV/EV 代码签名证书（约 ¥1000/年）后重新签名发布，后续版本可跟进。

## 更新日志（本版亮点）

**v0.20.44**

- 批量管理：批量删除完成后自动退出批量模式，关闭顶部批量工具栏
- 文档去重：按「完整路径 + 文件名」规范化判断（含正/反斜杠、大小写），重复导入同一文件不再产生重复条目，而是刷新并打开原文档
- 文档信息面板：新增「位置」项，显示文件所在目录（悬停可见完整路径）
- 磁盘文件保存：已有磁盘文件 Ctrl+S 直接覆盖保存；仅首次保存或无路径时才弹「另存为」，保存与另存为彻底分离
- 磁盘文件刷新：重新打开文档、窗口重新聚焦时自动读取磁盘最新内容（外部软件修改后同步）
- 启动优化：修复启动瞬间左侧闪现空白框
- JSON 工具：支持混合文本中仅序列化 JSON 片段（含半截 JSON），并在原文中高亮标记有问题的位置
- 查找/替换：修复弹窗偶发不显示、上一项/下一项导航失灵，弹窗可拖动，导航按钮重新设计
- 文档排序：排序功能增加开关，默认关闭（保持创建顺序稳定）
- 桌面版导入：改用原生文件选择器，导入文件自动关联磁盘路径
