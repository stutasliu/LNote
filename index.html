功能特性

📝 编辑器（CodeMirror 5）

  • 12 种语言语法高亮：Markdown / JSON / XML / HTML / JavaScript / Python / CSS / SQL / Shell / YAML / C·Java·C++ / Mermaid
  • 编辑辅助：括号自动配对与补全、代码折叠、多光标编辑、行号点击选行、自动缩进、智能补全
  • 体验细节：查找历史记忆、深浅色主题切换、状态栏实时显示行/列/编码/语言

👁 文档与实时预览

  • Markdown 实时预览：marked 渲染 + highlight.js 代码高亮 + KaTeX 数学公式，编辑即所见
  • Mermaid 图表：流程图 / 时序图 / 思维导图实时渲染，支持缩放平移
  • 思维笔记（富文档）：块编辑器（标题 / 引用 / 待办 / 代码 / 表格 / 图片等块），文档软件式左侧大纲（目录 + 搜索）
  • Bubble Menu：选中文本自动浮出快捷排版工具条，无需记忆快捷键

🛠 工具集

  • JSON / XML：格式化与压缩；混合文本中可只序列化 JSON 片段（含半截 JSON），并高亮标记问题位置
  • 文本处理：转义/反转义、Unicode↔中文、Base64、URL 编码、大小写转换、全角半角、去重、缩进计算
  • 查找/替换（仿 EverEdit）：正则支持、全文档高亮、批量替换、多行匹配、规则收藏
  • 更多工具：文件比较（双栏行级 diff）、编码转换、时间戳工具、代码段插入、剪贴板历史、图片查看器（缩放/平移）

💾 磁盘文件与数据

  • 本地文件集成：打开/导入本地文件，Ctrl+S 直接覆盖保存；仅首次保存才弹「另存为」
  • 自动同步：外部软件修改文件后，重新打开或窗口重新聚焦时自动读取磁盘最新内容
  • 智能去重：按「完整路径 + 文件名」判断，重复导入不会产生重复条目；文档信息面板显示文件所在位置
  • 隐私安全：数据全部保存在本机（localStorage），无需联网、无账号、不上传任何数据

验证文件完整性

  • 复制上方对应文件的 SHA256 值
  • 在 exe 所在目录执行：
  • certutil -hashfile L.Note-setup-v1.0.1.exe SHA256
  • certutil -hashfile L.Note-v1.0.1-win64.exe SHA256
  • 比对输出哈希是否一致

  • **修复富文本文档点击「保存」提示保存失败**：根因是「另存为」原生对话框的文件类型过滤器描述含品牌名「L.Note」中的点号，pywebview 的 `parse_file_type` 只接受 `[\w ]+ (*.ext)` 形式并会抛 `ValueError`，而该异常在平台 try 之外，直接导致整个保存流程失败；现前端过滤器描述改为「LNote 富文档 (*.json)」，Python 侧 `_ask_save_path` 对每条过滤器逐条校验、剔除非法项并在全部非法时回落到「所有文件 (*.*)」，双保险后保存恢复正常。，**新建文档默认名称统一为「无标题 / 无标题 2 / 无标题 3 …」**：此前普通文档走「无标题」，而快捷键 `Ctrl+N` 及富文本 / 流程图 / 思维导图 / 笔记等入口走「未命名文档 N」，两套命名规则并存；现全部新建入口统一复用 `nextAutoTitle()`，按现有「无标题」文档数量追加序号，侧栏与标题框显示一致。，**新建文档不再自动写入磁盘**：新建文档仅保存在本地存储，必须由用户显式点击「保存 / 另存为」才创建磁盘文件，此后编辑才会自动同步到磁盘；修复「新建的文档未经确认就落盘」的问题，未关联磁盘文件时状态栏显示「已保存」而非「已保存到磁盘」。，**预览内容安全加固**：Markdown / HTML 预览挂载前新增「标签 + 属性」白名单净化（丢弃 `
